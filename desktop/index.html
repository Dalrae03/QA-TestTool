Desktop Workspace

QA TestTool

Electron 데스크톱 셸에서 테스트 케이스를 작성, 조회, 수정, 삭제할 수 있습니다.

platform version

기본 연결 주소는 Spring Boot 서버 `http://localhost:8080` 입니다.

Test Cases

목록

데이터를 불러오는 중입니다.

    Templates

    템플릿 공간

    반복되는 테스트케이스를 템플릿으로 저장해 빠르게 작성할 수 있습니다.

    Editor

    테스트케이스 작성

    1
    초안 작성

    템플릿을 불러오거나 새 테스트케이스를 작성합니다.

    2
    저장 완료

    저장 후 복제, 수정, 템플릿 저장이 가능합니다.

    3
    실행 기록

    선택한 테스트케이스에 대해 실행 결과를 남깁니다.

    초안을 작성한 뒤 저장하면 바로 실행 결과를 기록할 수 있습니다.

    새 테스트케이스를 저장할 준비가 됐습니다. * 표시는 필수 입력입니다.

    Test Run

    실행 기록

    저장된 테스트케이스를 선택하면 실행 결과를 기록할 수 있습니다.

    실행 결과를 저장하면 해당 테스트케이스의 이력에 추가됩니다.

      Template Builder

      템플릿 만들기

      반복되는 테스트케이스 구조를 템플릿으로 저장할 수 있습니다.

      템플릿을 저장한 뒤 사이드바에서 바로 불러올 수 있습니다.
