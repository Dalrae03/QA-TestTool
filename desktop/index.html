    데이터 백업 / 복구

    전체 데이터(모든 프로젝트·테스트케이스·실행 결과 등)와 첨부파일을 하나의 백업 파일로 저장하고, 필요 시 그 파일로 복구합니다.

    ⚠ 복구하면 현재 데이터가 백업 시점 상태로 완전히 덮어쓰기 됩니다. 되돌릴 수 없으니 먼저 현재 상태를 백업해 두세요.

    기본 백업 폴더
    일마다 · 최근 개 보관

    마지막 백업: 없음

    자동 백업은 앱을 켤 때 마지막 백업이 설정한 기간보다 오래되었으면 기본 폴더에 조용히 저장됩니다. (앱이 꺼져 있는 동안에는 실행되지 않습니다.)

    새 프로젝트 만들기
    📥 엑셀/CSV로 테스트케이스 가져오기
    📊
    클릭하거나 파일을 드래그하여 업로드
    .xlsx, .xls, .csv 지원 · 엑셀은 시트=폴더, CSV는 '폴더' 컬럼=하위 폴더
    컬럼 매핑 가이드 (헤더명이 일치하면 자동 인식)
    제목/title, 설명/description, 전제조건/precondition, 스텝/steps,
    우선순위/priority, 상태/status, 유형/type, OS/os, 브라우저/browser
    📤 엑셀로 내보내기

    내보낼 항목을 여러 개 선택할 수 있습니다. 현재 프로젝트 범위로 내보냅니다.
